# 静态本地词库文章

## 运行规则

- 前台路由：`/Article/*`
- 数据目录：`app/common_data/Article/data`
- Nunjucks 模板：`app/common_data/Article/templates`
- 静态资源：`app/public/article_static`
- 运行缓存：`cache/fanmulu_article`
- 该路由生成页面时不查询 MongoDB、主句库或 Redis；访问请求仍会进入全局访问统计，但不会进入全局页面替换中间件。

请求的完整路径（含查询参数、不含域名和锚点）会先规范化，再计算 SHA256。`urlNumber` 取 SHA256 的前 8 个十六进制字符并转为无符号整数。同一个完整路径会固定选择文章、模板、关键词和相关链接。

## JSON 缓存

缓存文件只保存：

- 规范化请求路径
- SHA256 和 `urlNumber`
- 固定选择的模板
- 固定选择的本地文章文件
- 缓存结构版本与创建时间

缓存不保存最终 HTML，因此时间、访问展示值等动态字段会在请求时重新渲染。缓存按哈希前两位分成 256 个子目录，每个子目录最多保存 500 个 JSON；每个 Worker 每分钟最多新增 300 个缓存，防止随机 URL 请求无限占用磁盘。

## 后台管理

后台入口：`模板管理 -> 静态本地词库`。

- 只显示和操作 `data` 子目录中的 `.txt` 文件。
- 单个文件上限为 5MB。
- `data/links/*.txt` 是静态友链词库。
- `data/zh/*.txt` 是蜘蛛强引词库，默认关闭。
- PHP、证书以及其他非 `.txt` 文件不会通过管理接口读取或修改。

修改词库后，当前 Worker 的内存数据会立即失效；其他 Worker 最迟 60 秒重新加载文件。已经生成的 JSON 仍会固定文章文件和模板，如需全部重新选择，可在后台“运行与缓存”页手动清空缓存。
